# Shared files folder

This folder is synchronized into S3 buckets for both fleets.
Put the `*.deb` files here that need to be installed on all hosts.

## CrowdStrike

Go to https://edr-tools.platformops.ciso.ibm.com/download-sensors, choose the `Think (WW)` tenant,
`Ubuntu x86-64` as Platform, the `assets` asset group and the `N` version. Copy the downloaded file into this folder.
